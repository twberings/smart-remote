# Introduction
We have recently installed a veranda in our backyard. The veranda has lights and automatic sunshading that can be controlled by remotes. However, we would like to integrate these features into our smart home system so that we can automate their operation based on environmental conditions.

# Problem Statement
Both the lights and the automatic sunshading in the veranda are controlled by remotes. Because of this, it is not possible to incorporate these features into a smart home system. For example, it is not possible to automatically close the sunshading when the sun shines on the veranda or turn on the lights when it gets dark.

# Project Description
The goal of this project is to create a device that can control the lights and sunshading in a programmable way. This device will be located in the veranda and will be able to communicate with a smart home system (e.g. Home Assistant).

# Product Breakdown

The final product will consist of the following components:
- A device that can emulate sub GHz remotes and be configured to control the lights and sunshading in the veranda.
- A home assistant integration that allows the user to control the lights and sunshading from a smart home system.
